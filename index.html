Web Development Bootcamp

A hands-on, project-based path from your first line of HTML to a deployed full-stack application, built for people starting with no prior coding experience.

About This Course

This bootcamp is designed for career changers, students, and anyone who has always wanted to build things for the web but didn't know where to start. Rather than front-loading theory, each module centers on a real project, so you leave every week with something you built yourself and can show a hiring manager. By the end, you'll have shipped a complete web application from scratch.

What You Will Learn

Three stages, building on each other.

Stage 1

HTML & CSS

Structure real pages and style them with modern layout tools like Flexbox and Grid, from static mockups to responsive sites.

Stage 2

JavaScript

Learn the language of the browser: variables, functions, and the DOM manipulation that makes pages interactive.

Stage 3

Web Development Projects

Combine everything into three portfolio projects, including a full-stack app connected to a real database and API.
